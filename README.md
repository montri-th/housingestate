# CityMETER: Housing Estate

**แปลงจัดสรรกระจุกอยู่ที่ไหน และรอบแปลงมีหมู่บ้านแบบไหน** — เดโมแผนที่ 3 มิติของหมู่บ้านจัดสรรทั่วประเทศไทย ที่อ่านแปลงจัดสรรตามรายการจัดสรรที่ดินของกรมที่ดิน (ชุดเดียวกับ CityMETER production `?d=estate`) เป็นยอดต่อจังหวัดและอำเภอ แล้วเจาะลงถึงโครงการในบัญชีของผู้พัฒนาที่ทีมวิจัยเก็บ กรอบพื้นที่และอาคารในกรอบแบบ 3 มิติ ป้ายและราคาเริ่มตามหน้าเว็บ นิติบุคคลตามหลักฐาน รายงานของบริษัท สถานีรถไฟฟ้าใกล้แปลง และที่มาของทุกตัวเลข

- เว็บ: https://montri-th.github.io/housingestate/ (ไทย) · https://montri-th.github.io/housingestate/?lang=en (English)
- รุ่น 0.1.1 · 18 พฤศจิกายน 2569 · ข้อมูลจากชีตวิจัย “CityMETER Housing Estate Thailand — Research Master 2026-11-18” (อ่าน 18 พ.ย. 2569 จากไฟล์ส่งออกของเจ้าของ ไม่เผยแพร่ชีต ที่อยู่ของชีต หรือเซลล์ของชีต) · ยอดตรวจซ้ำกับ CityMETER production วันเดียวกัน
- โค้ดต่อยอดจาก CityMETER · University (https://github.com/montri-th/university @f610edb, citymeter-shell 0.6.2) ซึ่งต่อยอดจาก School และ Hotel · รุ่นนี้ส่ง citymeter-shell 0.6.3 (เพิ่ม Housing Estate ในตัวเลือกชุดข้อมูล)
- ทะเบียนชุดข้อมูล: `research.TH.housing_estate` · กลุ่ม Land

ข้อค้นพบแรก (snapshot ปัจจุบัน ไม่กรอง): **46% ของแปลงจัดสรรทั้งประเทศ (1,236,824 จาก 2,689,640 แปลง) อยู่ใน 3 จังหวัด — กรุงเทพมหานคร ปทุมธานี ชลบุรี** · เฉพาะแปลงบ้าน (บ้านเดี่ยว · บ้านแฝด · บ้านแถว) 47% (1,101,249 จาก 2,335,133 แปลง) · ในกรุงเทพมหานคร 24% ของแปลง (127,566 จาก 539,167) อยู่ใน 3 เขต — บางขุนเทียน ประเวศ สายไหม

> ชุดข้อมูล CityMETER Housing Estate จากรายการจัดสรรที่ดินของกรมที่ดิน (snapshot ของ CityMETER) · บัญชีโครงการของผู้พัฒนา · ประกาศและรายงานของบริษัท · OpenStreetMap · ตรวจ 18 พ.ย. 2569 · ขอบเขต จังหวัดและอำเภอของ CityMETER · วิธีนับ: `DATA_METHOD.md`

## ใช้งาน

```sh
npm start   # http://127.0.0.1:4173/
npm test    # unit tests บนข้อมูลจริง (node --test)
```

เป็น static site ไม่มี build step และไม่ต้อง `npm install` (Node ≥ 20 สำหรับ tests, Python 3 สำหรับ server) แผนที่โหลด MapLibre GL 5.6.2 จาก unpkg (ล็อก Subresource Integrity) และ tiles/glyphs จาก OpenFreeMap; basemap สร้างเองใน `js/shell/map-style.js` กราฟไม่ใช้ไลบรารีภายนอก ถ้าแผนที่โหลดไม่ได้ ข้อค้นพบ แผง กราฟ ตาราง และการค้นหายังใช้ได้ และหน้าบอกว่าส่วนไหนขาด

## สิ่งที่สำรวจได้

- **ข้อค้นพบแรก:** ทั้งประเทศ — จังหวัดที่มีแปลงจัดสรรมากที่สุด (ไม่เกิน 3) สัดส่วนของทั้งประเทศ พร้อมตัวตั้งและตัวหาร แท่งเทียบ “ทุกประเภทแปลง” กับ “เฉพาะแปลงบ้าน” และจังหวัดที่ไม่มีรายการ · เลือกจังหวัด — อำเภอที่มีแปลงมากที่สุดในจังหวัดนั้น (ไม่เกิน 3) · ไม่ตัดผ่านค่าที่เท่ากัน และไม่โฟกัสทุกจังหวัดที่มีค่า
- **แปลงจัดสรร | รายการ:** สลับตัววัดในคำอธิบายแผนที่ แผนที่ ป้าย ข้อค้นพบ อันดับ และกราฟเปลี่ยนตาม · ตัวกรองประเภทแปลง (บ้านเดี่ยว แฝด แถว อาคารพาณิชย์ ที่ดินเปล่า อื่น ๆ) วัดเฉพาะแปลงประเภทนั้น
- **จังหวัดและอำเภอ:** สีจังหวัด `li.supply` ครบ 41 ระดับ · เลือกจังหวัดแล้วอำเภอขึ้นเป็นชิปพร้อมตัวเลข · หน้าอำเภอ: แปลงตามประเภท อันดับและสัดส่วนในจังหวัด รายการจัดสรร (แปลงมากก่อน) และโครงการ
- **โครงการ:** หมุดตามประเภทบ้าน (สีและรูปทรง LDS) · กรอบพื้นที่จาก OpenStreetMap (“กรอบราว N ไร่”) และอาคารในกรอบเป็นสีชั้นข้อมูลที่ใช้งาน แบบเดียวกับวิทยาเขตใน University (ในกรอบใช้อาคารจากแหล่งที่มีมากกว่าระหว่าง CityMETER Building V4 กับ OpenStreetMap ตามเกณฑ์ 1.15 เท่าเดียวกับหน่วยอาคาร) · กดอาคารเพื่อดูแบบ 3 มิติ · ป้ายและราคาเริ่มตามหน้าเว็บ · ช่วงเปิดตัวที่ทีมวิจัยพบ · รายการจัดสรรที่จับคู่ · นิติบุคคล บริษัทแม่ และรายงานประจำปี · สถานีใกล้สุด · ภูมิประเทศ · โครงการรอบ ๆ
- **รายการจัดสรร:** แปลงตามประเภท ขอบเขตแปลง ผู้จัดสรร (เฉพาะนิติบุคคล) ที่ตั้งตามหน้าเว็บกรมที่ดิน ชื่ออื่น โครงการที่จับคู่ และลิงก์หน้าเว็บกรมที่ดินและ CityMETER
- **ผู้พัฒนา:** โครงการทั้งหมดในบัญชี ประเภทบ้าน แบรนด์ จังหวัด และโครงการเปิดตัวที่บริษัทรายงาน
- **ค้นหา:** ชื่อโครงการ ผู้พัฒนา อำเภอ จังหวัด หรือชื่อในรายการจัดสรร — ผลค้นหาอยู่บนสุดของแผง (ไม่เปลี่ยนตัววัด)
- **สถานีรถไฟฟ้า:** โครงการรอบ 1 กม. (ระยะตรง) จาก CityMETER Transit
- **กราฟและตาราง:** จังหวัด · ประเภทแปลง · อำเภอ · ตารางรายการจัดสรร 19,753 รายการ (25 ต่อหน้า)

## ข้อมูล

| ไฟล์ | เนื้อหา | โหลด |
|---|---|---|
| `data/estates.json` | ยอดต่อจังหวัดและอำเภอ (395 อำเภอ) · โครงการ 1,538 · ผู้พัฒนา 65 · แบรนด์ 391 · สถานี | ทันที |
| `data/extents.json` | กรอบพื้นที่ OSM 139 กรอบ (ODbL) | หลังหน้าแรก 1.2 วินาที |
| `data/portfolio.json` | หน้าโครงการ บัญชี นิติบุคคล บริษัทแม่ รายงานของบริษัท เหตุการณ์ คู่กับรายการ | หลังหน้าแรก 2.6 วินาที หรือเมื่อเปิดโครงการ |
| `data/records.json` | รายการจัดสรร 19,753 รายการ | หลังหน้าแรก 4 วินาที หรือเมื่อเปิดอำเภอ รายการ ตาราง หรือค้นหา |
| `data/area-index.json` · `data/provinces.geojson` | จังหวัดและอำเภอของ CityMETER production | ทันที |
| `data/building-units/` | หน่วยอาคาร CityMETER/OSM (ชุดเดียวกับ University) | ตามจังหวัดที่ดู |

สร้างใหม่ด้วย `scripts/build-data.py` (ดู `DATA_METHOD.md` §9) ชีตวิจัยและไฟล์ส่งออกไม่อยู่ใน repo

## ตรวจ

`npm test` ตรวจข้อมูล (ยอดตรง production ทุกจังหวัด แปลงตามประเภทรวมได้เท่ายอด คู่โครงการกับรายการ กรอบพื้นที่ ความเป็นส่วนตัว) มุมมองของแผง (บรรทัดที่มา ไม่มีข้อความเตือน) ข้อค้นพบ สี LDS ชุดกลาง (citymeter-shell 0.6.3) และ release · `npm run verify:live` เทียบไฟล์บนเว็บจริงกับ `handoff/handoff-manifest.json`
